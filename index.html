Play with your TikTok LIVE

  1. Install and open TikFinity Desktop for Windows on the PC you’ll play on. Link your own TikTok account in TikFinity Setup.
  2. Start your TikTok LIVE and connect to it in TikFinity. Keep the desktop app running.
  3. Select Connect in the game and allow local network access if your browser asks.
  4. Try the effect buttons first. If you want to verify the live connection, send a mapped gift or use TikFinity’s event simulator if it forwards events to the API. The last gift name appears below the effects.
  5. Capture the game window in OBS or TikTok LIVE Studio. Viewers send gifts on TikTok while you play here.

If the hosted page can’t reach TikFinity, run the game locally using the local launch instructions. The game connects to ws://localhost:21213/ and never asks for a TikTok password or stream key.
