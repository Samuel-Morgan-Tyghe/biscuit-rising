# Hiker

[Hiker by tevy](https://tevy.dev/models/hiker), version 1, LOD 0, is available under the [CC0 1.0 Universal public domain dedication](https://creativecommons.org/publicdomain/zero/1.0/). The source GLB also declares the licence in its asset metadata.

Skybreak includes a browser-compatible repackage of the [pinned source](https://tevy.dev/models/hiker/v1/lod0.glb). Meshopt buffer views were decoded and the Basis Universal textures transcoded into embedded JPEG and PNG images. The geometry, rig and 4 original animation clips were retained.

The model is 1.702 m tall, uses Y-up coordinates, and faces +Z. The original clips are `idle`, `walk`, `look_around` and `wave`. The walk plays in place.
