# Skybreak obstacle assets

All models and textures in this folder are by Kenney and released under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). The files retain their authored geometry, materials and textures. Textures originally stored beside a model are embedded in its GLB so the browser needs one request per obstacle.
