## Mountainside and industrial scenery

The models in `models/` originate from Poly Haven and use its [CC0 asset licence](https://polyhaven.com/license). Their base colour, normal and packed occlusion, roughness and metalness maps are embedded in the GLB files. The source glTF and dependencies were verified against the hashes in the Poly Haven files API. The browser versions use 1K textures and, where useful, simplified geometry.
